# Nexa product mockup

Interactive project-management MVP prototype with sample projects, boards, sprints, and tickets.

## GitHub Pages

In repository Settings → Pages, choose **Deploy from a branch**, then **main** and **/ (root)**. Save and wait for the deployment to complete.

## Updating the prototype

Replace `index.html` with the latest `nexa-review/product-review.html` and commit to main. GitHub Pages republishes the mockup.

This is a browser-based prototype, not a shared production backend. Uploaded attachments last for the current browser session. Selected preferences and workflow settings are stored in each visitor’s browser.
